# Stakeholder Analysis

| Stakeholder | Role | Interest/Expectations | Influence | How the System Affects the Stakeholder |
|---|---|---|---|---|
| Students (end users) | Primary users | Easy, reliable way to turn material into flashcards and study effectively | High | Saves time, improves exam prep, motivates via streaks/dashboards |
| Development team | Designers/developers/testers | Deliver a working system, gain SE experience, strong grade | High | Gains hands-on full-stack and AI integration experience |
| Course/Lab Instructor | Evaluator/supervisor | Proper SE practices, documentation, version control | High | Uses repo/report to assess process and technical work |
| OpenAI (API provider) | External service provider | Compliance with API terms and usage limits | Medium | Not directly affected; API changes could require adaptation |
| System/DB Administrator | Maintains hosting/DB if deployed | Stable, secure, maintainable system | Medium | Responsible for monitoring performance, applying updates |
| Future contributors | Potential future developers | Clear documentation, maintainable architecture | Low-Medium | Ability to extend system depends on documentation quality |
